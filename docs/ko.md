# Top-down Tiles — 정사각형 맵 보기

Top-down Tiles는 클래식 2D RPG 스타일로, 정사각형 격자 위에서 타일 맵을 곧바로 위에서 그립니다. 공유 엔진 Tile Rendering의 두 맵 보기 중 하나이며, 다른 하나는 Isometric Tiles입니다. RPG Plus는 이 보기를 씁니다.

![탑다운 보기의 정오 무렵 RPG Plus 마을: 집들, 가로등이 늘어선 광장, 마을 사람들, 연못, 그리고 주인공.](assets/village-topdown.jpg)

## 무엇이 바뀌고 무엇이 안 바뀌나

이 모드는 **맵의 한 칸이 어떻게 화면 픽셀이 되는지**만 정합니다. 각 칸은 타일셋 타일 하나 크기의 정사각형이고, 높이 솟은 물체는 칸을 바꾸지 않은 채 화면에서 더 높게 그려집니다.

나머지는 모두 다른 모드의 소유이며, 보기를 바꿔도 변하지 않습니다.

- **맵과 그 내용** — 타일, 건물, 사람, 상자 — 은 콘텐츠 모드에 있습니다(예: RPG Demo, Village Pack).
- **걷기, 충돌, 이벤트, 전투, 저장**은 RPG 모드의 몫이며, 두 보기에서 같은 격자를 씁니다.
- **그리기, 조명, 시간대**는 Tile Rendering이 맡습니다.

방향키와 WASD는 화면의 위·아래·왼쪽·오른쪽을 따라 움직입니다.

![같은 마을 맵의 두 보기: 왼쪽 탑다운, 오른쪽 아이소메트릭.](assets/same-map-two-projections.jpg)

## 켜는 법

게임 구성(**모드 및 컬렉션 → 컬렉션 → 게임 → 구성 편집**)에 이 모드를 넣고 **지도 투영**을 **탑다운**으로 정하세요. 설정 `tile.renderer`의 값은 `topdown`입니다.

```json
"settings": { "tile.renderer": "topdown" }
```

한 번만 실행하려면 명령줄에 `--tile-renderer=topdown`을 붙이세요. 이 렌더러만 포함하고 설정을 비워 둔 게임에서는 자동으로 쓰입니다.

## 문제가 생겼을 때

1. **맵이 비어 있습니다.** 게임의 **지도 투영**이 포함되지 않은 렌더러를 요청합니다. 이 모드를 넣거나 다른 투영을 고르세요.
